# Clasificación por edades de «Croac» 1.0.0

Las respuestas del juego. La clasificación la calcula cada sistema: la de abajo es la esperada, no una garantía.

## Google Play: cuestionario de IARC

| Pregunta (resumida) | Respuesta |
|---|---|
| Categoría | Juego |
| Violencia, sangre, miedo | No (una rana cae al agua y la partida acaba) |
| Contenido sexual, desnudos | No |
| Lenguaje soez | No |
| Sustancias controladas (drogas, alcohol, tabaco) | No |
| Juego de azar o simulado | No |
| Compras de bienes digitales | Sí (50 moscas y quitar anuncios) |
| Recompensas aleatorias de pago (cajas de botín) | No |
| Interacción entre usuarios, chat, contenido generado por usuarios | No |
| Comparte la ubicación del usuario con otros usuarios | No |
| Anuncios | Sí (anuncio recompensado de LevelPlay) |

Esperada: PEGI 3 con el aviso de compras dentro del juego ([Google: clasificaciones de contenido](https://support.google.com/googleplay/android-developer/answer/9859655)).

## App Store: preguntas de clasificación

Sin violencia, contenido sexual, lenguaje, sustancias, terror, juego de azar ni contenido generado por usuarios; con compras dentro de la app y anuncios. Esperada: 4+ en el sistema de 2025 (4+, 9+, 13+, 16+ y 18+) ([Apple: clasificaciones actualizadas](https://developer.apple.com/news/?id=ks775ehf)).
